# 0.2.0-preview

- Replace the mandatory browser-task chat handoff with a local observe/decide/act worker.
- Add a persistent browser with a separate live page per application and human takeover.
- Add search goals that connect discovery, assessment, eligible shortlisting, original résumé preparation, form scanning and approved filling.
- Preserve earlier fields on multi-step forms; stop when new fields invalidate approval.
- Support standard text, select, checkbox, radio and file fields; reject ambiguous repeated labels.
- Add real inference and browser/upload setup checks, user-owned PDF import and goal controls.
- Remove candidate names and private Google document IDs from product defaults.
- Keep runtime data outside the release, with existing-install compatibility and backup recovery.
- Replace the permanent development submission route with explicit destination configuration, exact approval, attempt reservation and receipt verification.
- Add mobile layout improvements and concrete blocker messages with saved checkpoints.
- Bundle the runtime dependencies in the Apple Silicon Mac build; retain source launchers.

Still awaiting employer-specific certification and automatic native-template document production. The preview does not claim universal completion of arbitrary job applications.
